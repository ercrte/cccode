# MewCode 命令系统 Spec

## 背景
MewCode 当前已经具备全屏对话、Agent Loop、上下文压缩、Plan Mode、权限控制、会话恢复和长期记忆等能力。现有斜杠命令能力仍偏轻量，部分命令语义直接散落在用户输入处理流程中，导致本地操作、界面状态变化和需要交给 AI 的预设请求缺少统一管理。

本阶段要设计一套内置斜杠命令系统。用户以斜杠开头输入时，系统应优先按命令处理，绕过普通 Agent 对话路径；只有普通文本输入才进入 AI 对话。这样可以让清屏、状态查询、模式切换、帮助说明等高频操作更快、更省 Token，且行为更确定。

## 目标
- 用户可以通过斜杠命令快速执行本地操作、调整界面状态或触发预设 AI 请求。
- 系统可以统一管理内置命令的名称、别名、描述、用法、类型、参数提示、可见性和处理行为。
- 系统在启动阶段发现命令名或别名冲突时立即失败，并给出可定位的错误信息。
- 系统可以在用户回车入口区分命令输入和普通对话输入，避免本地命令被误送给 AI。
- 界面可以支持命令补全、帮助展示、模式标记和状态刷新，而命令行为不绑定具体渲染细节。
- `/plan` 和 `/do` 作为持久模式切换命令使用：`/plan` 进入计划模式，`/do` 回到默认执行模式。

## 功能需求
- F1: 系统必须提供统一的命令登记能力，每条命令至少包含名称、别名、简短描述、用法示例、命令类型、可选参数提示、可见性和处理行为。
- F2: 系统启动时必须检查所有命令名称和别名是否冲突；任意两个可调用入口大小写折叠后相同，都必须视为冲突并阻止启动继续。
- F3: 用户提交空输入时，系统必须直接忽略，不显示错误，也不触发命令或 AI 请求。
- F4: 用户输入以斜杠开头时，系统必须把第一个空格前的内容作为命令名，剩余内容作为原始参数；命令名匹配必须大小写不敏感，参数内容除首尾空白外不得被额外改写。
- F5: 用户输入以斜杠开头但没有命中任何已登记命令时，系统必须显示清晰提示，并引导用户使用 `/help` 查看可用命令；该输入不得进入普通 AI 对话。
- F6: 用户输入不是斜杠命令时，系统必须按当前对话模式发送给 AI，不经过命令分发。
- F7: 命令必须按执行模式分为三类：纯本地命令、影响界面状态命令、预设提示词命令。纯本地命令只产生本地可见结果；影响界面状态命令可以改变界面或运行状态；预设提示词命令会把确定的请求内容送入当前对话，由 AI 继续处理。
- F8: 命令处理必须通过抽象的界面能力完成用户可见输出、用户消息发送、模式切换、Token 状态查询和状态刷新，不得要求命令直接依赖具体终端渲染实现。
- F9: 界面状态栏必须展示当前持久对话模式；默认执行模式显示 `[DEFAULT]`，计划模式显示 `[PLAN]`。
- F10: `/plan` 必须进入计划模式并刷新状态栏；该命令本身不要求用户提供需求，也不得作为普通用户消息发送给 AI。
- F11: `/do` 必须退出计划模式并回到默认执行模式，同时刷新状态栏；该命令本身不得执行此前保存的待执行计划。
- F12: 处于计划模式时，后续非命令用户输入必须作为计划模式请求发送给 AI；处于默认执行模式时，后续非命令用户输入必须作为默认模式请求发送给 AI。
- F13: 命令系统必须支持别名；用户通过主名称或任一别名调用命令时，行为必须一致。
- F14: 命令系统必须支持 Tab 补全；当前输入为斜杠命令前缀时，单匹配必须直接补全，多匹配必须显示可选菜单，隐藏命令不得参与补全。
- F15: `/help` 必须展示所有非隐藏命令的名称、别名、简短描述、用法和参数提示；当用户为 `/help` 提供某个命令名或别名时，必须展示该命令的详细帮助。
- F16: `/compact` 必须手动触发上下文压缩流程，并展示压缩结果或无需压缩的原因；它不得作为普通对话任务发送给 AI。
- F17: `/clear` 必须清空当前界面消息显示区域；是否保留会话上下文必须对用户可见，且不得意外删除持久会话记录或长期记忆。
- F18: `/session` 必须展示当前会话相关信息，至少包括会话标识、是否恢复自历史会话、当前消息数量和当前模式。
- F19: `/memory` 必须展示长期记忆的当前状态，至少包括记忆功能是否启用、用户级和项目级记忆是否可用，以及自动笔记是否启用。
- F20: `/permission` 必须展示当前权限状态，至少包括权限模式、当前会话临时规则概况，以及用户遇到权限确认时可以采取的下一步。
- F21: `/status` 必须展示当前运行状态，至少包括模型供应商、模型名称、当前模式、任务是否运行中、最近可用 Token 用量或未知状态、MCP 工具加载告警概况。
- F22: `/review` 必须触发预设代码审查请求，并把确定的审查提示送入当前对话交给 AI 处理；用户提供的参数必须作为审查范围或补充要求的一部分传递。
- F23: 预设提示词命令发送给 AI 时，界面必须让用户看见本次触发的命令或对应请求，避免用户无法判断 AI 为什么开始执行。
- F24: 命令执行失败时，系统必须在界面中显示可理解错误，并恢复输入能力；失败的本地命令不得追加为普通用户消息。
- F25: 命令系统必须内置十个高频命令：`/help`、`/compact`、`/clear`、`/plan`、`/do`、`/session`、`/memory`、`/permission`、`/status`、`/review`。

## 非功能需求
- N1: 纯本地命令和影响界面状态命令必须避免不必要的模型请求，保证响应快且节省 Token。
- N2: 命令解析、别名匹配、冲突检测和补全结果必须确定、可测试，不依赖模型输出。
- N3: 用户可见命令说明、错误提示和状态信息必须使用中文。
- N4: 命令系统不得破坏普通聊天、Agent Loop、上下文压缩、权限确认、MCP 工具、会话恢复和长期记忆的既有行为。
- N5: 命令元数据应能支撑未来扩展，但本阶段只要求内置命令，不要求用户自定义或动态加载。
- N6: 命令返回的状态信息不得泄露完整密钥、敏感环境变量或权限规则中的敏感内容。
- N7: Tab 补全和多匹配菜单在常见终端尺寸下必须可读，不得遮挡输入内容导致无法继续输入。

## 不做的事
- 不实现用户自定义命令。
- 不实现动态生成提示词。
- 不实现命令级权限控制。
- 不实现外部插件、Skill 市场或第三方命令加载。
- 不实现旧语义中的 `/plan <需求>` 生成待执行计划和 `/do` 执行待执行计划。
- 不要求 `/clear` 删除对话上下文、持久会话文件、长期记忆或上下文外置文件。
- 不要求 `/memory` 在本阶段创建、编辑或删除长期记忆。
- 不要求 `/permission` 在本阶段编辑权限规则或切换权限模式。

## 验收标准
- AC1: 注册两个大小写折叠后同名的命令、别名或命令名与别名时，系统启动失败，并显示冲突入口和涉及命令。
- AC2: 输入空白内容后，界面不新增消息，不调用命令，也不发起 AI 请求。
- AC3: 输入 `/HELP`、`/help` 或 `/help   status` 时，命令名按大小写不敏感匹配，参数按用户输入含义传给帮助命令。
- AC4: 输入未知斜杠命令时，界面显示包含 `/help` 引导的提示，且不会启动 Agent Loop。
- AC5: 输入普通非斜杠文本时，系统按当前持久模式发送给 AI；默认模式显示 `[DEFAULT]`，计划模式显示 `[PLAN]`。
- AC6: 输入 `/plan` 后，状态栏切换为 `[PLAN]`，界面显示已进入计划模式，且不会发起模型请求。
- AC7: 在 `[PLAN]` 模式下输入普通需求时，该需求以计划模式进入 AI 对话。
- AC8: 输入 `/do` 后，状态栏切换为 `[DEFAULT]`，界面显示已回到默认模式，且不会执行旧的待执行计划。
- AC9: 在 `[DEFAULT]` 模式下输入普通任务时，该任务以默认执行模式进入 AI 对话。
- AC10: 输入 `/help` 时，界面列出十个内置非隐藏命令，并展示名称、别名、描述、用法和参数提示。
- AC11: 输入 `/help review` 时，界面只展示 `/review` 的详细帮助和用法。
- AC12: 输入 `/compact` 时，系统触发手动上下文压缩，展示压缩结果或无需压缩原因，且该命令不会作为普通用户消息进入 AI 对话。
- AC13: 输入 `/clear` 后，当前界面消息显示区被清空，并显示上下文是否仍保留的提示。
- AC14: 输入 `/session` 后，界面展示当前会话标识、恢复状态、消息数量和当前模式。
- AC15: 输入 `/memory` 后，界面展示长期记忆启用状态、用户级和项目级记忆可用状态、自动笔记启用状态。
- AC16: 输入 `/permission` 后，界面展示当前权限模式、会话临时规则概况和权限确认说明，且不修改权限规则。
- AC17: 输入 `/status` 后，界面展示供应商、模型、当前模式、任务运行状态、最近 Token 用量或未知状态、MCP 工具加载告警概况。
- AC18: 输入 `/review` 或 `/review <范围>` 后，系统把确定的代码审查请求送入当前对话交给 AI，界面可见本次触发的审查请求。
- AC19: 在命令前缀只有一个非隐藏匹配时按 Tab，输入内容直接补全为该命令；存在多个非隐藏匹配时按 Tab，界面显示可选菜单；隐藏命令不出现在补全结果中。
- AC20: 任一本地命令执行失败后，界面显示错误，输入区恢复可用，失败命令不被追加成普通用户消息。
